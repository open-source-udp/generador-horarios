# generador de horarios para toma de ramos

como actualizar el repo?:

Acutualmente la actualizacion de las ofertas academicas de cada semestre es manual, una vez descargado el o los excel(s) correspondientes a la o las carreras deseadas se deben cambiar en el directorio apps/parser/input, en caso de ser CFG's e ingles deben ir en apps/parser/input/FORMACION-GENERAL, IMPORTANTE los archivos deben estar todos con separaciones de guion bajo(ING_EN_ADM_DE_EMPRESAS ✅ ING-EN-ADM-DE-EMPRESAS❌)

Para el desarrollo local una vez actualizado los excels en la ruta indicada se debe ejecutar
- npm i
- npm run build
- npm run dev
